TEAM 17 — PHASE-I REVIEW MICROSITE

Open index.html in a modern browser. This is a static site; no setup or account is needed.

The page follows the teacher's Phase-I sequence: A1 Understand, A2 Observe, A3 Define. It clearly marks student research, the final problem statement, causes, SDG relevance and approval as pending. No student findings are invented. The optional site-concept section summarizes the current demo features separately from Phase-I evidence.

- styles.css: layout and responsive visual design
- app.js: navigation behavior
